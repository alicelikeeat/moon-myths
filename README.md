# Moon Myths

用 SwiftUI 动画把《纯粹理性批判》的模型可视化的 iOS App。

| 页 | 内容 | 公式 |
| --- | --- | --- |
| 认识 | 粒子从物自体流过 σ（时空网格）和 κ（范畴）凝结为对象；可分别关掉 σ / κ | K = κ ∘ σ |
| 范畴 | 4×3 范畴表，点选后在时间轴上演示对应图型 | 数 / 度 / 持久 / 相继 / 并存 / ∃∀ |
| 背反 | 数学性：无尽回溯与无穷二分；力学性：现象因果链 vs 本体自由 | ¬(\|W\|<∞) ∧ ¬(\|W\|=∞) |
| 理念 | 沿统一性梯度上升、永不到达渐近线；意见/信念/知识开关 | sup = 理念 ∉ E |
| 边界 | 可知 ⊊ 可思 的同心圆，命题落点 | Im(κ∘σ) ⊊ 可思 |

## 构建

每次推送到 `main`，GitHub Actions 会在 macOS 上用 XcodeGen 生成工程、无签名编译，并在 Releases 发布 `MoonMyths-unsigned.ipa`。需要自行签名后安装（TrollStore、AltStore、Sideloadly 等）。

最低 iOS 17。
